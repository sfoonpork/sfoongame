About Pibb Game

Pibb Game is a free multiplayer browser game. Move your character around the map, collect mulch, climb the leaderboard, and chat with other players — no download or account required.

How to play

  • Open the game and you’ll automatically join a room
  • Use WASD or click to move; drag to pan the camera
  • Collect mulch pickups to score points
  • Chat with other players in the sidebar

Technology

The game runs entirely in your browser as a static web app. Multiplayer uses PeerJS and WebRTC for peer-to-peer networking — there is no dedicated game backend server.

Operator

Pibb Game is operated by an independent developer. Source code is available on GitHub.
